# 机器视觉知识库

一个面向机器视觉方案设计、调试和现场沟通的中文知识库。网站围绕实际问题组织内容，介绍相机、镜头、光源、2D / 3D 视觉、标定与机器人应用，并提供可操作的图解、案例和初步选型工具。

- [在线访问网站](https://fish404-yes.github.io/vision-knowledge-base/)
- [V1.0 归档版本](https://github.com/fish404-yes/vision-knowledge-base/tree/v1.0)
- [V1.0 使用与维护指南](docs/V1.0使用与维护指南.md)
- [V1.0 版本说明](docs/V1.0版本说明.md)

## 网站能做什么

| 入口 | 适合用来做什么 |
| --- | --- |
| 知识目录 | 按相机与采集、镜头与成像、光源与照明、2D、3D、标定与坐标、应用与排查查找知识。 |
| 互动图解 | 调整参数观察成像、二维视觉、三维视觉以及标定和机器人坐标关系。 |
| 应用案例 | 分步查看双 Mark 定位、对位贴合、缺陷检测、尺寸测量、方案选型等模拟案例。 |
| 选型与工具 | 根据任务初判 2D / 3D；估算相机、镜头与光源方案，或进行 3D 方案初选和规格对照。 |
| 图像实验区 | 使用内置示例或本地图片体验 ROI、阈值、连通域、形态学和测量线找边。入口在“选型与工具”。 |
| 项目与样件记录 | 在浏览器中记录需求、选型条件、样件观察和人工结论，并可导出备份。入口在“选型与工具”。 |
| 问题排查 | 按成像、定位、测量、机器人等现象查看检查方向和相关知识。 |

首页和导航中可搜索知识点、案例、互动图解和工具；桌面端使用侧栏，手机端使用顶部菜单。页面支持浅色和深色界面。

## 如何使用

1. 从首页搜索问题，或通过知识目录按主题查找。
2. 不确定方案时，进入“选型与工具”，先判断项目需要平面信息、高度信息还是两者结合。
3. 在互动图解中调整参数，或在应用案例中按步骤查看准备、处理和输出。
4. 有实际项目时，在“项目与样件记录”中保存条件、待确认事项和拍样结果。

### 本地预览 GitHub 仓库中的网站

仓库根目录就是静态网站，使用 HTML、CSS 和 JavaScript，无须安装前端依赖。安装 Python 3 后，在仓库根目录打开终端，运行：

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

然后访问 <http://127.0.0.1:8080/>；在终端按 `Ctrl+C` 结束服务。若端口被占用，可将 `8080` 换成其他空闲端口，并在地址中使用同一个端口。本地项目源码位于 `dist/`，从本机项目预览时请先进入 `dist/` 后再运行上述命令。

## 使用边界与数据

- 图解、应用案例和默认数据为简化或合成示例，不能替代真实相机、机械手、光源、样件试验和现场验收。
- 选型计算用于初步讨论，像素采样间距不等同于测量精度；实际选型需结合设备规格、光学条件、工艺公差及拍样结果。
- 坐标示例中的“物理坐标”是否为机器人基坐标，取决于实际标定和坐标定义；眼在手上每次拍照都要匹配其对应的机器人位姿。
- 图像实验区所选择的图片在当前浏览器内处理，实验区不会主动上传图片；刷新后需重新选择。部分工具可由用户主动保存到当前浏览器，清除浏览器数据或更换设备可能导致记录丢失，重要资料请下载备份。
- 在线网站页脚的访问计数依赖第三方 Hits 服务；它是累计访问次数，不是去重访客人数。网络不可用时可能无法显示。中国大陆的访问情况可能随地区、运营商和时间变化。

## 项目维护

GitHub 仓库存放的是发布用静态站点。本机开发项目中，`dist/` 是网站源码，`tests/` 是自动测试，`docs/` 存放项目文档，`.publish/github-pages/` 是发布仓库的本地副本；这些本机开发目录不一定包含在 GitHub 发布仓库中。

修改本机源码后，需要将实际改动同步到发布副本，检查后提交并推送至 GitHub；本机修改不会自动上线。测试命令、版本恢复方式和数据备份说明见 [V1.0 使用与维护指南](docs/V1.0使用与维护指南.md)。
