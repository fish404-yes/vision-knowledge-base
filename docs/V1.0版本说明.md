# 机器视觉知识库 V1.0 · 版本说明

- 归档日期：2026-11-10
- 归档标记：`v1.0`
- 项目定位：用于查阅机器视觉知识、观察交互示意和讨论初步方案的中文静态网站。

## 本版本包含

- **知识查询**：相机、镜头、光源、2D / 3D、标定坐标和应用排查等主题，支持搜索与相关内容跳转。
- **互动图解与应用案例**：包含 2D、3D、成像、光源、标定和机器人坐标等示意，以及双 Mark、贴合、测量与检测等分步模拟案例。
- **2D / 3D 方案初选**：从项目需要的信息出发判断方向；提供相机、镜头、光源初选，3D 条件讨论与 A/B 规格核对。
- **图像实验与项目记录**：在浏览器体验图像处理步骤，记录项目条件、样件观察和人工结论，可导出本地备份。
- **使用体验**：侧栏工作台、手机导航、深浅主题、问题排查和在线累计访问次数。

## 本版本的边界

网站中的图像、过程、数值及 3D 默认设备规格可能是合成或虚构示例；图解、初选和计算不能代替真实设备规格确认、标定、拍样或现场验收。像素采样、理论线频、设备标称重复性均不能单独代表项目最终测量精度。坐标输出的参考系应由实际标定链路确定。

项目记录保存在当前浏览器或用户主动导出的文件中；在线访问计数由第三方服务提供，计数可能受网络影响。网站不提供云端项目数据同步。

## 归档时的检查

- 本机开发项目现有自动测试：167 项通过（2026-11-10）。这覆盖已有模型与逻辑，不等同于全部现场工况验证。
- 上线前对首页放大后的选型入口进行了本地电脑端、手机端及深浅主题检查，并在线确认页面与入口跳转。
- 未连接真实相机、机械手、PLC 或实物样件开展现场验收；完整实物精度、节拍及长期运行结果不在本次检查范围内。
