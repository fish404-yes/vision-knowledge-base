# 机器视觉知识库 V1.0 · 使用与维护指南

本指南帮助首次使用网站和后续维护网站。网站是知识查询和模拟体验工具，不连接实际相机、PLC 或机械手。

## 一、打开网站

- 在线版：[机器视觉知识库](https://fish404-yes.github.io/vision-knowledge-base/)。
- 电脑端可从左侧导航进入各栏目；手机端使用右上角菜单。首页的大卡片可直接进入“选型与工具”。
- 如果页面显示旧版本，先保存正在编辑的内容，再刷新浏览器；电脑端可尝试 `Ctrl+F5`。在线访问情况可能因网络环境变化。

## 二、按实际问题查找

### 查设备与成像知识

在首页搜索“相机选型”“镜头焦距”或“光源选型”，也可在知识目录中按分类查找。文章中的关联内容可继续跳转到图解、案例或工具。

### 判断 2D 还是 3D

进入“选型与工具”，先选择项目需要输出的信息与高度变化条件：

- 颜色、字符、轮廓和平面位置等，可结合 2D 方案讨论。
- 高度、截面或空间形状等，可能需要 3D 或位移测量。
- 同时需要外观与高度时，可考虑组合方案。

判断结果只是下一步讨论的方向。实际还要考虑工件遮挡、表面、节拍、精度、视野和安装条件。

### 2D 相机、镜头与光源初选

在“选型与工具”中进入“2D 成像选型”，填写工件尺寸、视野余量、工作距离、最小特征和传感器条件，再结合工件表面与检测目标查看相机、镜头、光源和运动曝光的初步建议。页面支持展开 A/B 方案对照、镜头类型说明与其他估算。

采样像素、理论焦距与曝光位移都依赖输入条件和简化模型，不能直接保证测量精度或实际成像效果。

### 3D 方案初选

进入“3D 方案初选”，按项目填写测量范围、速度、采样间距、表面与输出要求等条件。页面提供一套台阶检测演示及两组虚构设备规格，供理解对照过程；应按真实项目替换或清空。

线扫频率、采样量及 A/B 结果是根据输入进行的理论核对；设备标称重复性、项目精度和现场验收不是同一个概念。未知条件应保持待确认。

### 图像实验和互动案例

“选型与工具”中的“图像实验区”支持内置示例和用户选择的本地图片，可体验 ROI、阈值、形态学、连通域及测量线。图片过大时，实验区会缩小到工作图像，页面给出的像素坐标和面积基于工作图像，而不是自动换算后的物理坐标。

“互动图解”和“应用案例”提供分步演示，例如双 Mark、眼在手上、ROI、找边、深度图与点云。图像、数据与坐标关系均按页面所述条件模拟；真实系统应核对标定、拍照位姿、坐标系与失效处理。

### 保存项目与样件记录

从“选型与工具”进入“项目与样件记录”，填写需求、选型摘要、样件观察与现场结论。需要时可以主动读取当前浏览中已打开的 2D / 3D 选型条件；读取只替换选型来源及摘要，实际条件仍需人工核对。

可使用“保存到本机”，也可下载文本或 JSON 备份并按需导入。浏览器本地保存不是云端备份；换浏览器、换设备或清理站点数据后可能无法读取，重要记录请保存导出文件。

## 三、本地预览与测试

### 预览本机开发项目

在本机项目的 `dist/` 目录中运行：

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8080/>，完成后在终端按 `Ctrl+C`。本机预览不增加线上访问计数。直接用 `file://` 打开时浏览器行为可能不同；本指南以 HTTP 预览为准。

### 运行已有自动测试

在**本机开发项目根目录**运行以下命令（需安装 Node.js）：

```powershell
node --test 'tests/*.test.cjs'
```

`tests/` 位于本机开发项目，GitHub 发布仓库主要保存静态站点，不包含这套本机测试。自动测试能检查已有模型和部分逻辑，不能代替真实浏览器操作和现场设备验收。

## 四、更新与恢复

- 平时在本机项目的 `dist/` 修改网站；核对后，将需要发布的文件同步到 `.publish/github-pages/`，检查 Git 变更再提交并推送 `main`。GitHub Pages 更新需要一点时间。
- 仓库根目录的 `README.md` 与 `docs/` 中的 V1.0 文档是面向 GitHub 阅读的说明；本机项目还保留更详细的 `使用说明.md` 和历史验收记录。
- [查看 v1.0 归档](https://github.com/fish404-yes/vision-knowledge-base/tree/v1.0)；在 GitHub 的该版本页面可浏览或下载源代码。该标签固定记录 V1.0，后续 `main` 的修改不会自动改变标签。
- V1.0 是版本归档，不是把整个 GitHub 仓库设为只读；后续仍可正常维护。恢复之前先备份当前改动，确认要还原的具体文件和版本。

## 五、现场使用前的核对

选型与坐标问题应结合相机及镜头真实规格、光源试样、工件高度和材质、标定精度、机器人坐标约定、节拍及安全要求逐项核对。软件中的示例、估算和排查线索不能替代现场拍样与验收。
